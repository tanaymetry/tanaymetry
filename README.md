## About

I build software around AI, systems and developer tools. My work sits between machine learning, backend engineering and systems programming, and I contribute to open source along the way.

- Machine learning and the infrastructure that runs it
- Backend services and APIs
- Performance-sensitive systems code in Rust and C++
- Developer tooling that removes everyday friction
